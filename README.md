### [저시력자를 위한 AI 기반 쇼핑 지원 음성 챗봇](https://github.com/obongbong/ai_shopping_chatbot)

- **Description:** 시각장애인(저시력자)이 온라인 쇼핑 시 겪는 복잡한 UI와 정보 과다 문제를 해결하기 위한 AI 기반 음성 챗봇입니다. (1년간 진행한 캡스톤 디자인 프로젝트)
- **Tech Stack:** Python, Rasa (NLU, Core), ChatGPT (GPT-3.5/4), Flask (API Server), STT/TTS (음성 인식/합성 API)
- **Highlights:**
  - 주요 기능 1: 음성 기반 쇼핑 플로우: STT/TTS API를 연동하여, 사용자가 음성 명령만으로 상품 검색, 정보 확인, 장바구니 추가 등 쇼핑 전 과정을 수행할 수 있는 인터페이스 제공
  - 주요 기능 2: Rasa & ChatGPT 하이브리드: Rasa NLU로 '상품 검색', '결제 요청' 등 핵심 의도를 정확히 파악하고, ChatGPT를 활용해 복잡한 상품 상세 정보나 사용자 리뷰를 자연스럽게 요약/설명.
  - 주요 기능 3: 정보 접근성 강화: 일반 쇼핑몰의 시각적 정보(이미지, 표)를 텍스트로 변환하고, 이를 다시 음성 친화적인 요약 정보로 가공하여 저시력자에게 핵심 정보를 효과적으로 전달.
